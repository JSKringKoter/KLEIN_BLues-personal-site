## Linux命令
命令就是Linux程序，执行命令就是调用linux程序处理问题。它的基本结构为：
```markdown
command [-options] [parameter]

command 命令
-options 命令的选项，可以控制命令的行为细节
parameter 命令的参数，多数用于命令的指向目标
```

## LS命令
ls命令的作用是列出目录下的内容，语法为：
```markdown
ls [-a -h -l] [路径]
```
不使用选项和参数时，该命令平铺列出当前工作目录下的内容
<span color="yellow">Linux系统启动时默认加载/home/username的目录，即\~或HOME目录。该目录是每个Linux用户的个人账户目录。下面两条语句是等效的：</span>
```markdown
cd ~
cd /home/username
```
- ls命令的参数和选项
	- `-a`：列出所有的文件，包含隐藏的文件和文件夹
		以`.`开头的文件和目录是Linux系统的隐藏文件
	- `-l`：以列表形式显示内容，并展示更多信息
	- `-h`：列出文件的大小，<span color="yellow">必须和</span><span color="red">`-l`</span><span color="yellow">连用</span>
	<span color="blue">参数可以连用，例如可以</span><span color="red">`-la`</span>

## CD命令和PWD命令
cd命令的作用是切换目录，语法为：
```markdown
cd [Linux路径]
```
cd命令没有选项只有参数，当不提供路径时，将回到HOME目录。
pwd命令的作用是打印当前工作目录，直接使用，没有选项和参数。

## 相对路径、绝对路径和特殊路径符
- 绝对路径以斜杠`/`开头，相对路径不以斜杠开头
- `.`表示当前目录
- `..`表示上一级目录
- `~`表示HOME目录

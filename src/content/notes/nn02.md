## 实际部署流程（可能）
```shell
tar -xf bz2.tar.gz          # 解压文件
cd bz2                      # 进入bz2
docker load < bz2-base.tar  # 加载本地镜像
docker-compose up -d        # 启动docker compose服务
```

## 磁盘挂载
**可能需要先取消ubuntu自动的磁盘挂载。**
外部设备必须挂载在根目录下的/mnt文件夹下。
- 挂载流程
```shell
sudo fdisk -l                   # 列出磁盘列表
sudo lsblk                      # 列出磁盘具体分区
sudo mkdir /mnt/mydev           # 在/mnt下创建挂载点
sudo mount /dev/sdc1 /mnt/mydev # 将磁盘挂载到/mnt下的挂载点下
sudo df -h                      # 查看是否挂载成功
sudo umount /mnt/mydev          # 取消挂载（弹出设备）
```
- 进程清理
```shell
sudo lsof +D /mnt/mydev         # 查看占用挂载点的进程
sudo fuser -mf /mnt/mydev       # 终止这些进程
```
## Docker
### 镜像相关
```shell
docker images                     # 查看本地镜像
docker pull image_name[:tag]      # 拉取镜像
docker build -t image_name .      # 从dockerfile构建镜像
docker build -f /path/to/dockerfile -t image_name .
docker rmi image_name             # 删除镜像
docker load < app.tar             # 从本机加载镜像
docker save -o filename.tar imagename:base    # 保存镜像
```
### 容器操作
```shell
docker ps           # 查看运行中的容器
docker ps -a        # 查看所有容器
docker run -d 8088:80 image_name    # 后台运行容器并映射端口
docker run -it image_name /bin/bash # 前台运行容器并交互式运行
docker stop container_id            # 停止容器
docker start container_id           # 启动容器
docker rm container_id              # 移除容器

docker exec -it container_id /bin/bash # 进入运行中的容器
```
### 日志
```shell
docker logs container_id          # 查看容器内部日志
```
### 权限处理
```shell
sudo usermod -aG docker $USER     # 将当前用户加入docker组
newgrp docker                     # 应用组更改
```

## Docker-Compose
```shell
docker-compose up # 前台启动
docker-compose up -d # 后台启动
docker-compose down  # 停止并清理容器、网络
docker-compose restart # 重启容器
docker-compose ps    # 列出所有服务
docker-compose logs  # 查看所有服务日志
docker-compose exec service_name bash # 进入某个服务
```

## 基本命令
### 文件和目录
```shell
touch a.txt     # 创建新文件
mkdir dir       # 创建目录
mkdir -p /a/b/c # 递归创建目录
```
### 复制和移动
```shell
cp a.txt b.txt  # 复制
mv a.txt b.txt  # 重命名
mv a.txt /dir/  # 移动
```
### 查看内容
```shell
cat a.txt        # 查看文件内容
```
### 解压与压缩
```shell
tar -xf filename.tar.gz    # 解压
tar -cf filename.tar.gz filedir/   # 压缩
```
### 辅助命令
```shell
pwd    # 查看当前路径
cd     # 切换
```

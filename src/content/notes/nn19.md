可以使用Arrays.copyOf()来拷贝到新的数组中：

## **二、面向对象部分**
### **构造器**
构造器是构造函数的另一种叫法。
构造器无法使用C++风格的列表初始化。

```plain text

    {
        this.ID = ID;
    }

```
Java中没有析构器，它能够自动完成垃圾回收。
### **方法**
Java中的实现不能放置于类外。放置于类内并不意味着声明为内联。若遇到同名问题，Java会发生错误，而不是同名遮掩机制。

每一个类都可以有一个main方法，可以在其中包含示例代码，单独运行该类文件时就可以运行该代码。

### **对象包装**
有的时候需要将int这样的基本类型变为对象类型，所有基本类型都有一个与之对应的类。包装器类不可变，不能修改其中的数据，且不能派生其子类。诸如ArrayList的容器类无法使用基本类型，此时可以使用包装器类将基本类型包装：
```plain text
ArrayList<int> array = new ArrayList<>();      //非法
ArrayList<Integer> array = new ArrayList<>();  //合法
```
可以直接传递基本类型给array，此时基本类型将自动包装为对象类型；反之，对象类型可以直接赋值给基本类型，称之自动拆箱。
```plain text
array.add(1);          //自动装箱
int i = array.get(2);  //自动拆箱
```
由于java中==运算符比较的是两者是否指向同一片内存空间，对于两个相同包装器对象的比较很有可能失败。此时需要使用equals方法：
```plain text
Integer int1 = 1000;
Integer int2 = 1000;
if (int1 == int2) return 1;      //不能这样比较
if (int1.equals(int2)) return 2; //应该这样比较
```

## **三、接口**
### **声明接口**
接口是对希望符合接口的类的一组需求，如果需要使用某方法，意味着类必须实现某接口。如果要使用Arrays类中的sort函数，则需要实现Comparable接口。
```plain text
public interface Compareable<T> {
    int compareTo(T t);
}
```
接口里的方法不提供实现，且自动声明为public。要声明一个类实现某接口，需要将类声明为实现给定的接口，且对接口中的方法提供定义。要声明一个类实现某接口，需要使用关键字implement：
```plain text
public class Player implements Complarable<Player> {
    private int level;

    public int compareTo(Player player) {
        return Intager.compare(this.level, player.level);
    }
}
```
### **接口的属性**
接口不是类，不能使用new来声明一个接口，但是可以将一个接口变量与实现了这个接口的一个具体对象绑定。
接口也有继承体系，可以使用extends关键字拓展接口，使其从泛用性强拓展到专用性强：
```plain text
public interface A {
    void func1();
}

public interface B extends A {
    void func2();
}

public interface C extends B {
    int level;
    void func3();
}
```
接口中不能包含实例字段，但可以包含常量。在接口内的实例字段自动声明为public static final。
可以将接口方法显式标记为public，将实例字段标记为public static final，但java语言规范建议不要使用冗余的关键字。
### **多个接口**
Java没有MI，但是可以实现多个接口。在接口中使用逗号隔开：
```plain text
public class Player implements A, B {
    ...
}
```
### **默认方法**
可以在接口中使用default来提供默认方法，这样实现接口的类可以不提供其实现：
```plain text
public interface A<T> {
    default int compare(T t) {
        return 0;
    }
}
```
### **默认方法冲突**
如果同时实现了两个接口，且这两个接口内有签名一致的默认方法，需要手动指定使用哪一个方法：
```plain text
interface Compare1<T> {
    default int compare(T t) {
        return 0;
    }
}

interface Compare2<T> {
     default int compare(T t) {
         return 1;
     }
}

public class Player implements Compare2<Player>, Compare1<Player> {
    public int compare(Player player) {
        return Compare1.super.compare(player);  //手动指定使用Compare1的compare方法
    }
}
```

### **散列集（HashSet）**
有一种众所周知的数据结构，可以用来快速查找对象，被称作散列表。散列表为每个对象计算一个散列码。要想查找每个元素在表中的位置，要先计算其散列码，再通过运算找到桶的编号。如果桶中已经有了元素，这种现象被称作散列冲突（Hash Collision），这时需要将新对象与原对象进行比较，查看这个数据是否存在。
Java库提供了一个散列集，可以用add方法插入元素，使用contains方法查看元素是否存在。当访问元素时，会通过一种看起来随机的方式，只有不关心集合中元素顺序时才使用HashSet。
这个实例程序读取一行字符，并打印其前20个不重复的单词。
```plain text
public class Main {
    public static void main(String[] args) {
        Set<String> stringSet = new HashSet<>();

        var cin = new Scanner(System.in);
        while (cin.hasNext()) {
            String temp = cin.nextLine();
            stringSet.add(temp);
        }

        var iter = stringSet.iterator();
        while (iter.hasNext()) {
            String temp = iter.next();
            System.out.println(temp);
        }
    }
}
```
### **有序树集（TreeSet）**
相较于HashSet，基于红黑树排序的树集在add数据时自动排序。添加数据时树集较慢，但查找较快。要使用树集，必须能够比较元素。这些元素必须实现了Comparable接口。
下面的实例程序使用实现了Comparable接口的测试类Item，比较其中的number实例字段。
```plain text
public class Main {
    public static void main(String[] args) {
        Set<Item> itemSet = new TreeSet<>();

        for (int i = 0; i < 20; i++) {
            Random random = new Random();
            itemSet.add(new Item(random.nextInt(101)));
        }

        Iterator<Item> iter = itemSet.iterator();
        while (iter.hasNext()) {
            System.out.println(iter.next());
        }
    }
}

public class Item implements Comparable<Item>{
    private int number;

    public Item(int number) {
        this.number = number;
    }

    public int compareTo(Item item) {
        return number - item.number;
    }

    @Override
    public String toString() {
        return "Item{" +
                "number=" + number +
                '}';
    }
}
```
### **映射（Map）**
映射分为散列映射和树映射，区别在于散列为无序而树为有序，它们都实现了Map接口。使用put函数向映射中添加元素，使用get来获取元素。在使用get时，必须提供key，因此必须记住key。
如果没有找到元素，则返回null，但null并不能包含有效信息，可以使用getOrDefault来使用自定义的默认值：

```plain text
int a = map.getOrDefault("wobuzhidao", 100);    //a将为默认值100
```

### **更新映射条目问题**
如果需要更换一个条目，但不知道是否存在，需要进行检查：
```plain text
Map<String, Integer> counts = new HashMap<>();
counts.put("word", counts.get("word") + 1);
```
这些代码在word出现后将其引用计数+1，但如果word第一次出现，则会抛出NullPointerException异常。补救方法是，使用getOrDefault函数：
```plain text
counts.put("word", counts.getOrDefault("word", 0) + 1);
```

### **排序与散排**
Collections类实现了一组方法，可以将给定的集合排列或散排，前提是其实现了Comparable接口。
- 排序：Collections.sort()
- 散排：Collections.shuffle()
```plain text
public class Main {
    public static void main(String[] args) {
        ArrayList<Integer> integerArrayList = new ArrayList<>();
        for (int i = 0; i < 30; i++) {
            integerArrayList.add(i);
        }

        Collections.shuffle(integerArrayList);
        System.out.println(integerArrayList);
        Collections.sort(integerArrayList);
        System.out.println(integerArrayList);
    }
}
```
List接口也有一个sort函数，但其接受一个比较器对象。Comparator.reverseOrder函数返回一个将元素倒序排序的比较器。下面的代码将integerArrayLIst的元素按逆序排序。
```plain text
integerArrayList.sort(Comparator.reverseOrder());
```

```plain text
class SimpleFrame extends JFrame {
    static final int DEFAULT_WIDTH = 300;
    static final int DEFAULT_HIGHT = 400;

    public SimpleFrame() {
        setSize(DEFAULT_WIDTH, DEFAULT_HIGHT);
    }
}
```
然后在主函数中创建这个类的对象，窗体对象创建后可以对其进行配置：
```plain text
public static void main(String[] args) {
    EventQueue.invokeLater(() -> {
        var frame = new SimpleFrame();
        frame.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);  //设置退出窗体时程序即退出
        frame.setLocation(100, 100);                           //设置窗体位置
        frame.setResizble(true);                               //设置是否可以调整大小
        frame.setVisible(true);                                //设置为可见
    });
}
```
- 属性
如下的一组代码称作窗体的一个属性，属性由一个get和一个set组成（对于boolean类型，get为is），将get或set后的单词小写即为其属性：
```plain text
public String getTitle()
public void setTitle(String title)
```
以及：
```plain text
public boolean isResizable();
public void setResizble(boolean resizable)
```
- 调整合适的窗体大小
要确定合适的窗体大小，需要先知道屏幕的大小。调用Toolkit类的静态方法getDefaultToolkit得到一个Toolkit对象，这个对象中的getScreenSize方法以Dimension对象保存屏幕大小信息。该Dimension对象中的height和width实例字段保存了高度的宽度信息。
```plain text
Toolkit tool = Toolkit.getDefaultToolkit();
Dimension screen = tool.getScreenSize();
int height = screen.height;
int width = screen.width;
frame.setSize(height / 2, width / 2);
```

```plain text
Image img = new ImageIcon("icon.gif").getImage();
```

### **添加组件**
图形界面的组件被放在JComponent的类中，要创建自己的组件时，需要先创建一个继承了JComponent的类，并覆盖其中的paintComponent方法，该方法将一个Graphics对象作为参量：
```plain text
class SimpleComponent extends JComponent {
    public void paintComponent(Graphics g) {
        g.drawString("我不知道", 100, 100);
    }
}
```
drawString方法用于打印字符串。
### **处理图形**
我们将使用Java 2D图形库绘制图形，需要获得Graphics2D的一个对象。这个类是Graphics的一个子类，要使用2D，需要进行强制类型转换：
`Graphics2D g2 = (Graphics2D) g`
可以使用Graphics2D对象的方法来处理图形。
